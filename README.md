# Sahil Nasariwala - Personal Portfolio

A modern, responsive personal portfolio website showcasing my skills, experience, and projects as a Front-end Developer.

## Features

- **Responsive Design**: Optimized for all device sizes
- **Modern UI**: Clean and professional design with smooth animations
- **Interactive Sections**: About, Resume, and Portfolio
- **Project Showcase**: Clean portfolio with project categories
- **Skills Visualization**: Progress bars for technical skills

## Technologies Used

- HTML5
- CSS3 (Custom properties, Flexbox, Grid)
- Vanilla JavaScript (ES6+)
- IonIcons for icons
- Google Fonts (Poppins)

## Sections

1. **About**: Professional summary and services offered
2. **Resume**: Education, work experience, and technical skills
3. **Portfolio**: Showcase of projects

## Getting Started

1. Clone or download the repository
2. Open `index.html` in your web browser
3. Or serve locally using a web server:
   ```bash
   python3 -m http.server 8000
   # Then visit http://localhost:8000
   ```

## Customization

To customize this portfolio for your own use:

1. Update personal information in `index.html`
2. Replace images in `assets/images/`
3. Modify colors and styling in `assets/css/style.css`
4. Update projects and content as needed
